### Android 14 Showcase

[Android 14](https://developer.android.com/about/versions/14) brought a lot of changes - let's see them in action:
- Font scaling is now non-linear and can scale way higher!
- Gendered strings!
- Granular access to user media
- Screenshot detection
- App screen sharing

You can see all of that and more nuanced changes if you install this app and give it a go
